# MC Panel 0.3.1

性能、稳定性与安全更新。无数据库结构变更。

## 本版重点

- **控制台更顺滑**：日志按 60ms 批量推送，前端按 `seq` 增量去重，缓冲区批量裁剪；模组服启动时显著减少 WebSocket 帧与 React 渲染压力。
- **指标采集更轻**：系统 CPU/内存改用 Node 原生 `os.*`，不再每 3 秒拉起 systeminformation/PowerShell；实例并行采样并共享进程枚举；系统概览复用最近采样。
- **备份与文件更快**：备份只遍历一次目录树，运行中备份在 `save-all flush` 冻结后规划；文件列表分批并发 stat；删除实例异步清理备份目录。
- **配置读取更省**：`server.properties` 按 mtime/ctime/size 缓存，面板写入后立即失效。
- **前端更轻**：sparkline 改为纯 SVG，移除 recharts 和约 314 kB 的 charts 分包；共享包增加 `./constants` 子路径，首屏不再打包 zod/schemas，`index` 降至 161.0 kB（gzip 52.0 kB）。

## 稳定性

- WebSocket 增加 75 秒心跳看门狗，休眠/断网恢复后自动重连，不再假死。
- 玩家数据只在服务器运行/孤儿状态轮询；右侧面板在玩家页不重复请求。
- 任务清理不会删除仍在运行的任务，超大世界备份超过 1 小时也不会丢失进度。

## 安全

- 升级 `@fastify/static` 10.1.7、`drizzle-orm` 0.45.4、`zod` 4.6.7，修复 3 个 high 级别依赖漏洞。
- CI 增加生产依赖审计（`npm audit --omit=dev --audit-level=high`）。
- 当前 `npm audit` 为 0 漏洞。

## 升级

- 无数据库结构变更，无需手动迁移。
- Windows 便携版：关闭面板 → 备份 `data/` → 解压新包 → 把旧 `data/` 复制到新包（或在 `.env` 中把 `DATA_DIR` 指向旧数据目录）→ 运行 `start-panel.bat`。
- 源码部署：保留现有 `data/`，执行 `npm ci && npm run build && npm start`。
