# MC Panel 0.4.0

Windows 桌面版首个正式版本。现有 Web 面板、Minecraft 服务器管理和数据全部复用，新增独立的原生窗口、托盘和安装器。无数据库结构变更。

## 桌面版

- 双击安装器或便携 exe 即可使用，不需要浏览器、命令行或预装 Node.js。
- Electron 原生窗口内运行现有 Fastify 面板；面板服务作为子进程监听 `127.0.0.1` 的随机端口。
- 系统托盘：打开面板、在浏览器打开、打开数据/日志目录、开机自启、关闭窗口时最小化到托盘、退出。
- 单实例：重复启动只聚焦已有窗口；关闭桌面应用不会停止 Minecraft 服务器。
- 首次启动可导入现有便携版/源码部署的 `data/`（`panel.db`、`secret.key`、备份）。
- 数据目录：安装版为 `%APPDATA%\MC Panel`；便携版为 exe 旁的 `mcpanel-data/`。升级和卸载默认保留数据。
- 大文件下载通过主进程流式写入用户选择的位置；支持 RCON 密码复制到剪贴板。
- 安全：BrowserWindow 使用 `contextIsolation` + `sandbox`，关闭 `nodeIntegration`；只允许本地面板 origin；权限请求默认拒绝（仅放行剪贴板）；下载禁止跨源重定向。

## 包含 0.3.1 的性能与安全更新

- 控制台日志 60ms 批量推送与前端 `seq` 增量去重；日志缓冲区批量裁剪。
- 系统指标改用 Node 原生 `os.*`，实例指标并行采样；备份单次遍历、文件列表并发 stat。
- `server.properties` 元数据缓存；玩家轮询只在运行状态进行；WebSocket 心跳看门狗。
- 升级 `@fastify/static`、`drizzle-orm`、`zod`，修复 high 漏洞；CI 依赖审计。
- 首屏 `index` 约 161.0 kB（gzip 52.0 kB），无 recharts/charts 分包。

## 安装与升级

### 推荐：安装版

1. 运行 `MC-Panel-Setup-0.4.0.exe`（每用户安装，无需管理员）。
2. 首次启动选择“新建”或“导入现有数据”。
3. 后续升级安装新版本即可，`%APPDATA%\MC Panel` 中的数据保留。

### 便携版

- 运行 `MC-Panel-0.4.0-portable.exe`；数据在 exe 旁的 `mcpanel-data/`。
- 便携版每次启动都需要把约 535 MB 的应用解压到临时目录，首次启动可能需要 1–2 分钟；日常使用建议安装版。
- 仍提供服务器便携 ZIP `mcpanel-0.4.0-win-x64.zip`（`start-panel.bat`），供无桌面环境或高级用户使用。

### 从旧版迁移

1. 关闭旧面板。
2. 启动桌面版，在首次启动对话框选择“导入现有数据”，选中旧 `data/` 目录。
3. 导入完成后原管理员、实例、备份和计划都会保留。

无数据库结构变更；如使用源码部署，保留现有 `data/` 后执行 `npm ci && npm run build && npm start`。

## 已知限制

- 安装器和便携 exe 未签名，Windows SmartScreen 可能提示“来源未知”；请从本仓库 Releases 下载并核对 `SHA256SUMS.txt`。
- 仅支持 Windows 10/11 x64。
- 0.4.0 不包含自动更新；新版本需手动从 Releases 下载。桌面代码签名和自动更新计划放到后续版本。
- 桌面应用退出时若面板服务仍在启动，可能留下一个由系统回收的短暂进程；正常退出会先通过 IPC 停止面板服务。
- 安装后约 535 MB（Electron + 内置 Node 24 + 服务端依赖）；便携版每次启动解压较慢。
- 单实例锁按数据目录隔离；安装版与便携版可以同时运行，但会使用不同数据。
